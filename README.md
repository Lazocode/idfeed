# 🚗 IDFeed

> Plataforma SaaS para gerenciamento de veículos, oficinas e ordens de serviço.

O **IDFeed** é uma plataforma desenvolvida para facilitar o gerenciamento de informações relacionadas a veículos e serviços automotivos, conectando oficinas a um sistema centralizado de consulta e gerenciamento.

O projeto está sendo desenvolvido de forma incremental, com novas funcionalidades sendo adicionadas continuamente.

---

## 🎯 Objetivo

O objetivo do IDFeed é oferecer uma solução simples e moderna para:

* 🔎 Consultar veículos através da placa e CPF
* 🏢 Gerenciar oficinas cadastradas
* 🚗 Gerenciar veículos
* 🧾 Criar e acompanhar ordens de serviço
* 📦 Gerenciar materiais utilizados nos serviços
* 👤 Controlar usuários e permissões
* ✅ Realizar processos de aprovação de oficinas
* 📊 Centralizar informações em um dashboard

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/idfeed.git
```

### 2. Acesse a pasta

```bash
cd idfeed
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

Após iniciar o projeto, acesse a URL disponibilizada pelo Vite no terminal.
